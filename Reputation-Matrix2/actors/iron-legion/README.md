## Install

1. Copy `Reputation-Matrix2/portraits/iron-legion/` to `<Foundry Data>/portraits/iron-legion/` (512-px PNGs with transparency, cut from the Forge's renders).
2. **One click:** with the Waluipedia Mass Import module enabled, Actors sidebar → **Import** → upload [`import.json`](import.json). It files the twelve under *Iron Legion / Cordon Command*, */ Frontline Patrol*, */ Surveillance & Recon* and */ Magitek Automata* with their fixed `_id`s.

## Rebuild

```bash
python3 tools/build-forge-packets.py iron-legion          # write the actors
python3 tools/build-forge-packets.py --check               # verify (check-all)
python3 tools/build-forge-packets.py plates iron-legion   # cut npc-forge/…/renders → portraits/iron-legion/
python3 tools/foundry-bridge.py combine Reputation-Matrix2/actors/iron-legion \
    --out Reputation-Matrix2/actors/iron-legion/import.json --world iron-legion
```
