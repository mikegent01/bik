# Fawful's Forces — Foundry VTT actors

Twelve dnd5e NPC exports (system 5.3.3, core 14) for **Fawful's Forces**,
the Cackling Menace's garrison inside Peach's Castle in the campaign's present
(1040 BF) — built as something for the party (levels 3–8) to fight, CR 1/2 to
7. All twelve are generated by
[`tools/build-forge-packets.py`](../../../tools/build-forge-packets.py) from
the NPC Forge roster [`data/forge/fawfuls-forces.json`](../../data/forge/fawfuls-forces.json)
— **do not hand-edit**; change the roster and re-run the generator
(`check-all` runs its `--check`).

## Install

1. Copy `Reputation-Matrix2/portraits/fawfuls-forces/` to
   `<Foundry Data>/portraits/fawfuls-forces/` (512-px PNGs with transparency,
   cut from the Forge's renders). Paths in the JSON are
   `portraits/fawfuls-forces/<id>.png`. Or let the bridge do it:
   `python3 tools/foundry-bridge.py install-images Reputation-Matrix2/actors/fawfuls-forces --foundry-data "<Foundry Data>"`.
   An actor whose plate is not cut yet wears `icons/svg/mystery-man.svg`
   (flag `waluipedia-sheets.art: "pending"`) until the next build.
2. **One click:** with the
   [Waluipedia Mass Import module](../../Foundry/mass_import/README.md) enabled,
   Actors sidebar → **Import** → repo packet *Fawful's Forces*, or URL
   `https://raw.githubusercontent.com/mikegent01/bik/gh-pages/Reputation-Matrix2/actors/fawfuls-forces/import.json`
   (or upload [`import.json`](import.json), or paste
   [`macros/import-fawfuls-forces.js`](../../Foundry/mass_import/macros/import-fawfuls-forces.js)
   into a script macro). It files the twelve under *Fawful's Furious Freaks /
   Machines of Fury*, */ The Bean Garrison* and */ Lieutenants of Fury* with
   their fixed `_id`s; running it again after a rebuild updates them in
   place. The suite's Sync carries the packet inside the world's
   `import.json` as well, so a GM who syncs never needs this step.

## Rebuild

```bash
python3 tools/build-forge-packets.py fawfuls-forces          # write the actors
python3 tools/build-forge-packets.py --check                 # verify (check-all)
python3 tools/build-forge-packets.py plates fawfuls-forces   # cut npc-forge/…/renders → portraits/fawfuls-forces/
python3 tools/foundry-bridge.py combine Reputation-Matrix2/actors/fawfuls-forces \
    --out Reputation-Matrix2/actors/fawfuls-forces/import.json --world fawfuls-forces
```

## Rules of the packet

- Hostile tokens (`disposition -1`), unlinked; the Boom-Crawler and the
  Countess are 2×2.
- Mechanics are 2024-rules NPC statblocks: flat save DCs, attack bonuses
  from the CR's proficiency, rider damage as extra damage parts, recharges
  and daily uses on the activities, legendary actions spending
  `resources.legact`.
- "Mustarded", the Fury Meter rage and the helm rules are written on the
  sheets that use them; the faction article (`fawful_forces`) stays the
  authority on the occupation itself.
- Fawful's Forces (present day, Fawful) ≠ Fawthful's Forces (1035 BF,
  Side B) — the two groups in `actors/folders.json` are different people.
