## Install

1. Copy `Reputation-Matrix2/portraits/regal-lion/` to `<Foundry Data>/portraits/regal-lion/`.
2. **One click:** with the Waluipedia Mass Import module enabled, Actors sidebar → **Import** → upload [`import.json`](import.json). It files the thirteen under *Iron Legion / Manor Command*, */ Regal Lion Knights*, */ Manor Wardens* and */ Heavy Beasts & Auxiliaries* with their fixed `_id`s.

## Rebuild

```bash
python3 tools/build-forge-packets.py regal-lion          # write the actors
python3 tools/build-forge-packets.py --check             # verify (check-all)
python3 tools/build-forge-packets.py plates regal-lion   # cut npc-forge/…/renders → portraits/regal-lion/
python3 tools/foundry-bridge.py combine Reputation-Matrix2/actors/regal-lion \
    --out Reputation-Matrix2/actors/regal-lion/import.json --world regal-lion
```
