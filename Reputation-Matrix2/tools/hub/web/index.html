How this works

  • Item Piles reads Reputation-Matrix2/commerce/shop-purchases.json, resolves each receipt against the live shop catalog, and writes one Foundry item-pile actor per character.
  • Character Creator builds a Foundry actor from characters.json, Reputation-Matrix2/events/events.json, and factions.json, with starting gear picked from the real shop catalog.
  • Tools lists every script in tools/ with its docstring, CLI flags, and functions — click to read the source or run it.
  • Everything generated lands in tools/hub/.hub-out/ and is git-ignored.
