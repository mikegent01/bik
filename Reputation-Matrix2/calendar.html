📅 Calendar Merged into Waluipedia

The standalone calendar.html and its old logic (calendar.js, calendar-data.js, calendar.css depending on research/quests/plagues) has been retired and merged into the main encyclopedia.

New location: Waluipedia → Calendar (Intuitive) — same URL as the integrated view: battlefield.html#/calendar

What changed — intuitive date system:

  • 12 months, 365 days (Deepwinter 35 days, others 30). 7 weekdays: Soldas, Lunadas, Terras, Mercurias, Jovias, Venerias (Rest), Saturias (Rest).
  • 4 seasons: Verdant Spring (Veridia/Bloom/Floria), Golden Summer (Efferd/Highsun/Harvestide), Crimson Fall (Aethel/Darkmoon/Frostfall), Hoarfrost Winter (Deepwinter/Firstlight/Chillwind).
  • BF counts UP toward present — log number, not countdown. 722 BF oldest record, 1040 BF current game date (Harvestide 18, 1040 BF). Larger year = more recent.
  • Weekday = absoluteDay % 7 where absoluteDay = year*365 + daysBeforeMonth + (day-1). Rest days are Venerias, Saturias.
  • All events/battles/trials/majorBattles are now parsed via same parseYear/parseMonth/parseDay and appear as dots on the month grid. Click day → inspect.

Main page updated:

  • Hero now shows full date: e.g., Harvestide 18, 1040 BF — Venerias (Rest Day) — Golden Summer
  • Mini calendar widget for current month on front page (today highlighted, days with events underlined).
  • On This Day is now dynamic — finds events/battles that happened on same month/day in any year, not static text from mainPage.json.
  • Calendar catcard added to Explore grid, sidebar link added.
  • New data files: calendarWeekdays.json, calendarSeasons.json, calendarMeta.json — enriched calendarMonths.json with season/icon/description.
