# Bowser troop bases — Hunyuan 3D inputs

Each file is a **single 1024 × 1024 full-body 3/4 character plate** on a plain studio backdrop. These are individual inputs for Hunyuan 3D; they are not a contact sheet and should not be combined before mesh generation.

| File | Troop role | Construction points to preserve |
|---|---|---|
| [koopa-troopa-base.png](koopa-troopa-base.png) | Standard Koopa infantry | Yellow upright Koopa, cream belly, green shell with white rim, brown shell straps, exposed three-clawed feet and hands. No clothes or weapon. |
| [goomba-base.png](goomba-base.png) | Standard Goomba infantry | Chestnut mushroom body, cream lower face, thick brows, two small fangs, tiny arms, broad dark feet. No suit or executive props. |
| [hammer-bro-base.png](hammer-bro-base.png) | Heavy projectile troop | Yellow stocky Koopa, green helmet, green spiked shell, black cuffs, green sandals, single low-held iron hammer. |
| [magikoopa-base.png](magikoopa-base.png) | Field caster | Yellow Koopa face, large circular spectacles, blue star-patterned robe and hood, green shell edge, crooked wooden wand with amber gem. This is an unnamed troop caster, not Kamek. |

## Hunyuan notes

- Use one PNG per mesh generation; all four have a complete single silhouette and a neutral, unbroken backdrop.
- Keep the characters stylized and compact. Do not add human musculature, realistic reptile anatomy, facial hair, tactical plate armour, or extraneous capes.
- The troops are broad Bowser-force production bases rather than claims about one named archive event. Their colours and props are intentionally distinct so they read apart in an assembled battle.
