## Commit 3 — Past selves: one character, several sheets (`#/sheets/<id>/<version>`)

* **`ERAS`** in `tools/build-character-sheets.py` — one entry per version (`version`, `era`, `label`, `when`, explicit `level`, the usual bespoke spec, its own `pc=` tuple). `build_eras()` builds each through the same `build_generated()` path as the bespoke sheets, so they are player characters with every feature bound to an article quote. ## Commit 4 — `tools/foundry-studio.py`: the Foundry++ character editor suite

**The mess it is for.** The screenshot: a folder with `ai bg icons portraits tokens` subfolders and a floor of loose files — `Axie.png`, `bearr.png`, `bonesclean.webp`, `cfleadtoad.png`, `court-chambermaid.png`, `court-mage-a.png`, `danm.png`, `dfas.webp`, `BrickBlock_-_2D_art.webp`, a dozen `<hash>-removebg-preview.png/webp` cut-outs, `28.-bowser's-stolen-castle.mp3`, `ar.wav`. Nothing in Foundry can point at a file whose name is a hash.

**What it does** (stdlib Python only; `py tools\foundry-studio.py …` on Windows, Data folder defaults to `%LOCALAPPDATA%\FoundryVTT\Data`):

* **`scan <folder>`** — inventory of the loose files with format, pixel size (pure-Python PNG / WebP / JPEG / GIF header parsing), guessed kind and what the archive thinks each one is: `danm` → *Dan (dan) 86 %*, `bonesclean` → *Bones 75 %*, `court-chambermaid` → *Castle Chambermaid* from the 955 roster, hash names → *say who it is*. Suggestions come from `characters.json` names and ids plus the 955 packet, `difflib` + substring, never the same character twice.
* **`sort <folder>`** — the interview the user asked for, one file at a time: **name** (suggestion as the default; nothing as the default for a hash-named cut-out), **kind** (`portraits tokens icons bg ai audio other`; guessed from the subfolder or the name — `-removebg-preview` is a token; a `.png` cannot be filed as audio), **faction** (defaults from the XP ledger, `?` lists the 22 `factions.json` ids plus the ledger's keys and `unaffiliated`), **version** (blank = now, `955-bf` = a past self). Enter accepts, `s` skips (remembered), `d` moves to `_trash/`, `q` stops, a closed stdin stops too — it never files everything by default. Each file lands at `<kind>/<faction>/<slug>[--<version>].<ext>`; `foundry-studio.json` next to them remembers name, faction, character id, version, notes and files. `--answers file.json` replaces the keyboard (and is the whole conversation — other files stay loose), `--auto` takes only suggestions ≥ 85 %, `--all` walks the pre-existing subfolders too.
* **`list` / `rename` / `edit` / `delete`** — the manifest with the sheet facts beside each entry (*character bones · sheet PC L5 +1 era*), filters by faction and kind; `rename` re-keys and moves the files; `edit` changes faction (files move, empty folders are pruned), character (must exist in `characters.json`), version (re-keys with the `--<version>` suffix) and notes; `delete <slug>` or `<slug>/<kind>` goes to `_trash/` unless `--forever`.
* **`link [<folder>] [--data …]`** — inside Foundry's Data folder: `npc/waluipedia/actors` → the repo's `Reputation-Matrix2/actors` tree (so the module README's `npc/waluipedia/actors/worlds/midlands` and the macro's `npc/waluipedia/actors/cast` are real directories), `npc/waluipedia/art/<faction>/<slug>/portrait.png · token.webp · icon.png · bg.jpg · ai.png`, `npc/waluipedia/audio/<faction>/<slug>.mp3`. Symlink first; on Windows a directory falls back to a junction (`mklink /J`) and a file to a hard link, then to a copy (`--copy` forces copies; `--dry-run`, `--no-actors`). `studio-links.json` records what was created and **`unlink`** removes exactly that.
* **`versions <id> [--stub <version>]`** — a character's present sheet, past selves and other real files with their `#/sheets/<id>/<version>` routes; `--stub` prints a ready-to-paste `ERAS` entry (level capped at the ledger, the present sheet's ability scores, AC, class and species filled in) — the builder stays the only thing that writes sheets.
* **`adopt <folder> <slug> [--as <id>]`** — a library portrait becomes `Reputation-Matrix2/portraits/<id>.<ext>` (refuses to overwrite without `--force`) and prints the rebuild command.
* **`changes <folder> --out changes.json`** — a `foundry-bridge.py apply` file: for every entry, `{match: {name}, set: {img, "prototypeToken.texture.src"}}` pointing at the linked Data paths; era entries match `<name> (955 BF)`.

**Also.** The module macro `import-from-data-folder.js` pointed at `npc/waluipedia/cast`; it now matches the `link` layout (`npc/waluipedia/actors/cast`) — zip rebuilt (26354 B). Module README gained the studio walkthrough; `actors/README.md` and the root README docs table point at it.

**Tests.** `tools/tests/test-foundry-studio.py` — 44 checks on a throwaway library built from the screenshot's filenames (real PNG/WebP headers): suggestions, scan, sort by answers file / by stdin prompts / `--auto`, the folder layout and manifest, skip / trash / quit / closed-stdin, list filters, rename, edit (faction move + prune, character, version re-key, bad key, bad character), delete to `_trash` and `--forever`, link dry-run / symlinks / `--copy` / `--no-actors` / missing Data folder, unlink, versions (Mario, Bowser, the Kamek stub), adopt (copy, refuse overwrite, needs an id), changes. Wired into `tools/check-all.py` as *foundry studio*.
