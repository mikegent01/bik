# Map modes: Species / Religion / Culture / Factions — 2026-09-08

## What shipped
The world atlas (`#/maps` desk, `mountAtlasMapV2`) gains four categorical map
modes. Pin COLOR now carries the dominant category while pin SIZE keeps the
existing log ladder (fed by filed adherents or residents):

| Mode | Category source | Pin glyph | Size = |
|---|---|---|---|
| Species | census top race per POI | initial letter, hashed color | filed members |
| Religion | census top faith GROUP (4 cosmological groups) | group icon (☀️🐾⚙️🌀) + group color | filed adherents |
| Culture | cultures linked to the pin's faction / article / region | initial letter, hashed color | residents |
| Factions | POI `factionId` via the faction registry | logo art (letter fallback) + registry color | residents |

Species/Faiths used to be diversity-count lenses ("3 peoples"); they are now
dominant-category lenses (Faiths renamed to Religion). The detail panel keeps
the full filed lists, gains a 🏛️ culture line, and the faction row now shows
the registry name + logo art instead of a grey dot. Legends list top
categories with counts; totals read "N of M pins filed".

## Data (filed only, no invented canon)
- **Religion**: `wahCensusByPoi` character census + `RELIGION_DATA` groups.
  Ungrouped denominations bucket as "Other faiths". Coverage is thin by
  construction (filed sightings only): midlands 15/207 pins, mushroom 8/271.
- **Culture**: NEW `cultures` census section. A pin inherits cultures whose
  `relatedArticles` name its factionId, its articleId, or its location's
  region (token match). Midlands 94/207, mushroom 44/271.
- **Factions**: POI `factionId` → `systems/faction-registry.js` (name/color/
  logo). Colors cover 141/141 map factionIds; 83 have valid logo files, the
  rest fall back to initial letters. Missing files swap on `error`, never a
  broken-image box.
- Census bridges were widened with the same filed-presence proxy: event
  `relatedArticles` backstop location resolution, and character
  `relatedArticles` naming a pinned place count as associations (+30%
  species/faith pins).
